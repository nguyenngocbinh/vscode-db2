# Changelog

All notable changes to this extension are documented here.

## [0.2.0] - 2026-09-04

### Added
- Marketplace-ready extension metadata and packaging scripts.
- DB2 SQL snippets for SELECT, CTE, MERGE, procedures, cursors, handlers, SIGNAL, temporary tables, window functions and temporal queries.
- VSIX packaging exclusions.
- GitHub Actions workflow for package validation and optional Marketplace publishing.

### Improved
- Expanded DB2-focused syntax grammar.
- Improved Marketplace keywords and metadata.

## [0.1.1]

- Added repository, homepage and issue tracker metadata.
- Improved DB2 grammar coverage.
